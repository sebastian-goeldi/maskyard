# MaskYard

<p align="center">
  <img src="../../../logo.png" alt="Crane lifting a chip" width="420">
</p>

Build, store, and inspect chip layouts with Python and KLayout. MaskYard stores cell geometry and hierarchy in a database so you can reuse generated cells and browse their layouts.
