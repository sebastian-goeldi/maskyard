# PDK 与参数化单元

使用 `get_or_create_pdk(name)` 获取指定名称的工艺设计套件（PDK），并用 `pdk.pcell()` 将 Python 函数注册为参数化单元（PCell）的工厂函数。工厂函数接收版图参数并返回一个 `Cell`。在函数内调用 `pdk.create_cell()` 即可使用自动分配的名称。

每个 PCell 工厂都有持久化的标识。规范化后相同的参数可以跨会话复用已保存的单元。同一主机上的多个进程通过生成锁协调相同的调用。即使不同主机上的进程都计算了同一结果，数据库的唯一性约束也会防止写入重复的缓存记录。

PCell 调用默认同步执行。如需通过专用写入线程保存，请参阅[批量写入](../how-to/batched-writes.md)。如需提交远程任务，请参阅 [Ray 指南](../how-to/ray.md)。
