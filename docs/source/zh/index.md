# MaskYard

<p align="center">
  <img src="../../../logo.png" alt="起重机吊起一枚芯片" width="420">
</p>

使用 Python 和 KLayout 创建、存储和查看芯片版图。MaskYard 将单元的几何图形和层次关系保存在数据库中，方便复用已生成的单元并浏览版图。
